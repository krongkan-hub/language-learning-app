กฎลายเส้น (ขยายใหญ่)

  • เส้นนอก = สีของส่วนนั้นเข้มขึ้นประมาณ 50% ไม่ใช้สีดำเลย (selective outline)
  • แสง มาจากซ้ายบน เงาหนึ่งขั้นทางขวาของหน้า ใต้คาง และใต้ผม
  • จมูก เป็นเส้นเงาลงทางขวาสองถึงสาม pixel แล้วจบที่รูจมูก เป็นจุดที่บอกว่าเป็นสไตล์ตะวันตกชัดที่สุด
  • ตา มีตาขาวสอง pixel กับลูกตาหนึ่ง pixel คิ้วเป็นตัวหลักที่บอกอารมณ์
  • ความหลากหลาย มาจากรูปหน้า (กลม, ยาว, เหลี่ยม), หนวดเครา, ริ้วรอยตามอายุ และแว่น
